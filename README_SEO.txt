After deploying:
1. Verify https://www.boardbagfees.com/robots.txt
2. Verify https://www.boardbagfees.com/sitemap.xml
3. Add boardbagfees.com as a Domain property in Google Search Console.
4. Add Google's TXT verification record at the DNS provider (currently Wix).
5. In Search Console > Sitemaps, submit: sitemap.xml
6. In URL Inspection, inspect https://www.boardbagfees.com/ and Request Indexing.
7. In Bing Webmaster Tools, import the site from Google Search Console.
